## 🛠️ Tech Stack

### Core Technologies

- **Oracle Service Bus (OSB)** 14c - Primary focus for mediation and routing
- **Oracle SOA Suite** 14c - For orchestration and workflow
- **Oracle JDeveloper** 14.1.2.0.0 - IDE for development
- **Oracle WebLogic Server** 14.1.2.0.0 - Application server

### Development Tools

- **SoapUI** - SOAP/REST service testing
- **Postman** - REST API testing
- **Git** - Version control
- **Maven** - Build automation

### Languages & Standards

- **BPEL 2.0** - Business Process Execution Language
- **XSLT 1.0/2.0** - XML transformations
- **XQuery** - XML query language
- **XPath 1.0/2.0** - XML navigation
- **WSDL 1.1** - Service descriptions
- **XML Schema (XSD)** - Data structure definitions
